## P1 — Client-side error na dashboard po wklejeniu YT URL

### Root cause (odkryty podczas P4)
Dashboard wysyłał `{url: "..."}` do `/api/v1/process`, który wymaga `{video_url, site_config, options}`. Mismatch API contract → 422 json_invalid → React crash.

### Co zrobiono
1. Zmieniono endpoint: `/api/v1/process` → `/api/v1/generate` (nie wymaga WP credentials)
2. Zmieniono pole: `url` → `video_url` (prawidłowy kontrakt Pydantic)
3. Zmieniono provider: `gemini` → `claude` (ANTHROPIC_API_KEY ustawiony, GEMINI_API_KEY brak)
4. Dodano guard `res.json().catch()` na SyntaxError (HTML response z nginx 502)
5. Dodano null-safety na `schema/chapters/faq`
6. Dodano ekstraktory `extractChapters()` + `extractFaq()` z @graph JSON-LD
7. Dodano przycisk "Kopiuj" dla JSON-LD output
